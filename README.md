# PENT Королёв — демонстрационный сайт

Статический адаптивный демосайт PENT Королёв (Королёв, просп. Космонавтов, 27Б, 3 этаж).

## В демоверсии

- Фирменная чёрно-жёлтая стилистика по предоставленным промоматериалам и оригинальный логотип.
- Блок реальных акций: счастливые часы, день рождения, киновечер, игра «Кубы».
- Кофейное меню с ценами из предоставленной карточки.
- Интерактивный календарь с выбором дня и часов, отображением остатка мест.
- Адаптивная версия для телефона и компьютера, фиксированное меню, звонок и контакты.
- Все изображения и статические файлы хранятся в репозитории.

## Важное про бронирование

Количество мест и расписание в календаре — **демонстрационные**. Сайт не связан с реальной системой бронирования. Подтверждение брони — по телефону. После согласования дизайна можно подключить сервер и админку, чтобы получать и обновлять реальную доступность.

## Запуск

Откройте `index.html` или используйте GitHub Pages из ветки `main`, корень репозитория. Сборка не требуется.

## Перед публичным запуском

Уточнить актуальность цен, акций, графика работы и право размещать фирменные материалы; проверить правовые требования к публичным материалам заведения. Для демо установлен `noindex,nofollow`.
