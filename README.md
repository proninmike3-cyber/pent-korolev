# PENT Королёв — демонстрационный сайт

Статический адаптивный концепт для PENT / Penthouse Korolev. Без админки, аналитики, пользовательских форм, cookies и внешних JS-библиотек. Работает на обычном статическом хостинге, а также локально через `index.html`. Оформление не выдаётся за официальный брендбук.

## Содержание

- Главный экран с быстрым бронированием по телефону.
- Атмосфера, игры, чай, кинопросмотры / трансляции по анонсам.
- Сводка впечатлений гостей с отсылкой на отзывы Яндекс Карт (пересказ, не выдуманные цитаты).
- Важные условия визита без непроверенных тарифов или обещаний.
- Адрес, график, переход в Яндекс Карты, телефон.

## Что не подтверждено и требует согласования

1. Официальный логотип, фирменные цвета, право использования фотоматериалов.
2. График на праздники, правила компании из 5+ человек, длительность брони.
3. Точный актуальный пробковый сбор и условия допуска собственных напитков.
4. Ссылки на официальные MAX / Telegram / ВК, чтобы не подставлять неправильные аккаунты.
5. Полнота и корректность адресных данных, возможные дополнительные реквизиты для публикации.

Все фотографии заменены на **оригинальные локальные SVG-иллюстрации-концепты** в `assets/`. Они не представляются как реальные фотографии заведения. При наличии разрешения владельца лучше заменить иллюстрации на локально хранящиеся фото интерьера.

## Юридические ограничения

Закон о рекламе РФ (38-ФЗ, ст. 7, п. 8) запрещает рекламу кальянов, табака, никотинсодержащей продукции и курительных принадлежностей. Здесь не размещено продвижение кальянов / табака, их фото, цены, призывы употреблять и скидки. Основное содержание — информационная карточка лаунж-пространства, настольные игры, чай, график, адрес и телефон. Это снижает риски, но не заменяет проверку юристом перед публикацией. См. https://www.consultant.ru/document/cons_doc_LAW_58968/3bfc26317bd01efad6f67aadf9981b248a57ef4b/ и позицию ФАС об информационных сайтах: https://www.consultant.ru/document/cons_doc_LAW_458545/.

Для демо установлен `noindex,nofollow` — снять только после согласования с владельцем.

## Запуск

Откройте `index.html` в браузере. Для проверки локальным веб-сервером:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/

Сайт без сборки, без серверных зависимостей и без внешних изображений. Разработан в первую очередь под desktop/mobile. SVG-иконки вместо эмодзи для корректной работы на iPhone.
