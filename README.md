# PENT Королёв — демонстрационная версия сайта

Адаптивный статический сайт лаунж-пространства PENT Королёв.

## Что на сайте

- Главный экран с фотографией интерьера, контактами и быстрым переходом к бронированию.
- Фирменное чёрно-жёлтое оформление и логотип по предоставленным материалам.
- Акции: счастливые часы, бонус ко дню рождения, киновечер и игра с кубами. Карточки акций свёрстаны на HTML/CSS, а не вставлены как скриншоты сторис.
- Кофейное меню с ценами по присланному изображению.
- Интерактивный демонстрационный календарь: выбор даты, интервалы по часам и условный остаток из 10 мест.
- Контакты, адрес, часы работы, ссылка на Яндекс Карты.

## Важно для демонстрации

**Календарь показывает условные значения.** Он не подключён к реальному наличию мест, не создаёт бронирования и не заменяет подтверждение администратора. До подключения backend-интеграции посетителям стоит бронировать по телефону.

Акции, цены и часы взяты из предоставленных промоматериалов. Перед запуском для клиентов актуальность условий должна быть подтверждена владельцем. Подключение онлайн-бронирования, приём персональных данных, админка и аналитика в демо не реализованы.

Все используемые изображения и логотип размещены локально в `assets/`, внешних фотохостингов нет. Фотография интерьера — предоставленная для проекта.

## Запуск

Откройте `index.html` в браузере либо запустите локальный сервер:

```bash
python -m http.server 8000
```

Сайт без сборки и серверных зависимостей, подходит для GitHub Pages.
