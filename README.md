# PENT Королёв — демонстрационный сайт

Статический адаптивный сайт-презентация лаунж-пространства PENT Королёв. Неофициальная демонстрация для согласования с владельцем. Создан без админки, базы данных, сторонних JavaScript-библиотек и внешних фотохостингов.

## Что внутри

- Главный экран с реальной фотографией интерьера и фирменным визуальным языком PENT.
- Секции «Атмосфера», «Акции», «Кофе с собой», «Выбрать время», «Контакты».
- Интерактивные категории кофейного меню и цены из предоставленной карточки меню.
- Афиши заменены на самостоятельные HTML/CSS-карточки акций. SVG-иконки вместо эмодзи.
- Демонстрационный календарь с выбором дат, времени и количества гостей: остатки мест искусственные, бронирование через сайт не создаётся, подтверждение только по телефону.
- Полностью локальные изображения: `assets/pent/interior.webp`, `assets/pent/logo.png`; графика `assets/ui/brush.svg`.
- Доступность: семантические секции, доступные названия интерактивных элементов, клавиатурное управление категориями меню, настройки уменьшенного движения.

## Запуск

Откройте `index.html` в браузере либо запустите `python3 -m http.server` в папке проекта. Статический хостинг: GitHub Pages, ветка `main`, корневая папка.

## Примечания

Часы работы, актуальность акций, цены, разрешения на использование фотографий и макет логотипа нужно подтвердить у владельца перед коммерческим запуском. Сайт подготовлен как коммерческая демонстрация. `robots=noindex,nofollow` задан до согласования с владельцем.
